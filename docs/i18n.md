# 多语言

当前支持简体中文（`zh-CN`）、繁體中文（`zh-TW`）和 English（`en`）。登录页右上方与登录后的顶部栏都可选择语言。

首次访问按浏览器语言选择，支持英语地区变体及简繁体地区 / 文字别名；其他语言默认使用英语。选择保存在浏览器本地，同一浏览器刷新后仍然有效。也可分享 `/?lang=en`、`/?lang=zh-CN` 或 `/?lang=zh-TW` 链接，链接指定值优先于本地偏好。

切换会重新加载界面，保留现有登录与当前模块。配置编辑器有未保存内容时先请求确认；其他尚未提交的表单可能需要重新填写。日期、时钟和相对时间使用所选语言的 Intl 格式。

界面、按钮、提示、状态、常见任务消息及服务端错误使用共享语言目录。API 根据 `Accept-Language` 协商语言，并返回 `Content-Language`；没有可用偏好时保留简体中文，以兼容已有 API 客户端。错误码、鉴权、CSRF 与权限规则不随语言改变。

地图 / 插件标题、作者描述、玩家内容、文件路径、配置正文与原始游戏日志保留原文；不会通过自动替换整个页面来翻译用户数据。第三方插件、原生工具和操作系统返回的未知错误也可能保留原始语言。历史任务和审计记录不会被改写。

## 代码结构

- `public/i18n.js`：语言选择、协商、参数插值、历史消息显示和语言控件。
- `public/locales/en.js`：英语目录。
- `public/locales/zh-TW.js`：繁体中文目录。
- 简体中文使用原始消息键作为默认文本，缺失键回退原文。

当前每个翻译目录包含 894 条应用消息。消息键为简体中文原文；动态参数使用 `{0}`、`{1}` 等占位符。占位符名称与出现次数必须与原文一致。不要把 HTML、JavaScript、真实用户名或部署地址写进翻译。

```js
translate('合集共 {0} 项。选中需要安装的地图；每个项目单独下载、校验并记录结果。', {0: count});
```

新增语言时添加一个与英语目录键相同的模块，在 `public/i18n.js` 中注册语言 ID、原生名称、目录与地区别名，并扩展语言和浏览器测试。新增界面文本时显式调用翻译函数，按 HTML / 属性上下文保留必要转义；不要翻译用户的服务器名称、文件内容或游戏命令。

```bash
npm run check
npm test
npx playwright install chromium
npm run test:e2e
```

繁体中文初稿使用 OpenCC 文字与词汇转换，并对界面及术语做检查；欢迎通过 Pull Request 改善用词。OpenCC 仅用于生成初稿，不是面板的运行依赖。
